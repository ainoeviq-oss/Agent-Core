- Ambiguous unkeyed conflicts are persisted in `memory_conflicts`, both branches become `conflicted`, and cross-principal/project conflict creation is rejected.

- Archived/tombstoned memory is excluded from normal recall; tombstoned memory remains excluded even when history is requested.
- Compaction removes inactive graph edges, rebuilds FTS deterministically, and performs an integrity check without deleting raw memory events.
