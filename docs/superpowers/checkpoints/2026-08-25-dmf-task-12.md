## GREEN implementation

- All 11 route-gated operational tools pass through one `routeGuarded` choke point.
- After successful route validation, DMF records `memory.operation_intended`; after execution it records `memory.operation_succeeded` or `memory.operation_failed`.
- Route validation rejection—including `ROUTE_MEMORY_GUARDRAIL_BLOCKED`—records `memory.operation_rejected` before returning the existing route error result.
- Actual failures/rejections create deterministic derived `failure` memories keyed by tool + bounded input signature so earlier failures can be recalled before repeating the same action.
- Audit is deliberately best-effort: audit persistence errors are swallowed and never mutate operational MCP outputs.
- Affected paths and verification state are captured deterministically from actual route/input metadata.
- Secret-bearing values are bounded/redacted before memory persistence. `write_file` content and edit old/new text are represented only by byte counts. Command text is stored only as a bounded redacted preview plus byte count. Result `stdout`, `stderr`, `content`, and similar payloads are represented by byte/count metadata, not full bodies.
- `memory_events.raw_text` remains NULL through the store append-only path.

## Debugging evidence
