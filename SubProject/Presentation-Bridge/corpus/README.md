# Controlled PPTX Corpus

Generate with:

```bash
npm run build
npm run fixtures
```

Generated fixtures are placed in `corpus/generated/` and are intentionally Git-ignored to keep the repository source-only.

The twelve fixtures cover controlled text/shapes, image/SVG media, theme/layout inventory, tables, charts, transparency, transforms, notes/hyperlinks, OOXML transition/timing, package media inventory, and a mixed-content deck.

Fixture names describe the intended stress area; they do **not** constitute target compatibility claims. Target support is recorded only after target-native evidence exists.
